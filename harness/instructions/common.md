## 공통 작업 지침

- 구현을 바꾸기 전에 서비스 저장소에서 관련 요구사항, 기술 결정, 테스트를 확인한다.
- 좌석 상태나 트랜잭션을 바꿀 때는 동일 좌석 동시 요청, 선점 만료와 확정이 겹치는 경우, 중복 확정 요청 중 변경에 해당하는 검증을 실행한다.
- 동시성 제어 방식을 비교할 때는 기준 구현을 유지하고 동일한 부하 및 데이터 조건을 사용한다.
- 실험 수치를 보고할 때는 실행 명령과 측정 결과를 연결하고, 실행하지 못한 검증은 명시한다.
- 서비스의 기술 결정은 서비스 저장소의 ADR에 기록한다.
- API 키, 비밀번호, 개인정보는 코드, 문서, 프롬프트, 실험 데이터에 넣지 않는다.
