SeatGet에 적용하는 방법

서비스 PR에 Brain 커밋과 생성 지침을 함께 기록하면 팀원이 같은 규칙으로 작업을 시작할 수 있습니다.

처음 받은 팀원

Git과 Node.js 22 이상을 준비하고 서비스 저장소를 복제합니다.

git clone --recurse-submodules https://github.com/seatget-team/seatget.git
cd seatget
node .brain/scripts/sync.mjs --check

기존에 복제했다면 서비스 루트에서 git submodule update --init -- .brain을 실행한 뒤 확인합니다.

지침을 고친 팀원

  1. Brain에서 지침을 고치고 PR 검토를 마칩니다.
  2. 서비스에서 git -C .brain fetch origin을 실행하고 git -C .brain checkout --detach <Brain-커밋>으로 검증할 버전을 선택합니다.
  3. node .brain/scripts/sync.mjs와 node .brain/scripts/sync.mjs --check를 실행합니다.
  4. .brain, AGENTS.md, CLAUDE.md 변경을 서비스 PR에서 함께 검토합니다.

ChatGPT에서 작업할 때는 과제에 필요한 원본 문서와 공통 지침을 대화에 첨부하거나 연결된 GitHub에서 참조합니다.

A · Brain 미적용 재현같은 서비스 커밋에서 .brain, 서브모듈 설정, Brain이 생성한 지침 두 파일을 제외했습니다.
B · 현재 적용 방식같은 커밋에서 .brain의 고정 버전을 가져오고 루트 지침 두 파일을 검사했습니다.

해석 범위 이 결과는 문서 접근성, 지침 배포, 버전 재현성을 보여줍니다. AI 답변 품질이나 작업 시간은 동일 과제와 모델로 반복 실행하는 별도 실험에서 비교할 수 있습니다.
